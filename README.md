核心框架： 分数压力自适应成长控制器 + 食物承诺系统 + 2-ply轻量战术评分 + 极端兜底。400ms deadline保护，每个环节超时即提前返回。
【P0】构建障碍集
所有存活蛇身和蜘蛛精加入 forbidden。
【P1】候选方向过滤（空间评估用「模拟移动后」的障碍集）
关键：Flood Fill ：构建一张"走完这步之后"的地图（头前移、尾解封），再从新头出发评估空间
强蛇封杀：长度 ≥ 自身的敌蛇，其所有合法下一步格子均排除出候选。
空间阈值（大于阈值则加入候选方向）：
● 正常：`max(8, 蛇长×1.45)`；若蛇长≥5 且 HP≥65，还须同时满足 `蛇长×2.0` 
● 低HP（<65）或短蛇（<5）：`max(8, 蛇长+3)` 
● 成长模式：`max(10, 正常阈值×0.68, 蛇长+4)` 且出口≥2 
若三种情形都筛不出任何候选，放弃阈值限制，直接返回所有安全方向中空间最大的方向。
【P2】极端追尾兜底
候选最大空间均<蛇长+3 时触发。BFS 找最短到达自己尾巴的候选方向，直接返回。
【P3】食物承诺系统（标记承诺方向，不直接返回，传入P6获得最大权重加分）
HP<34（极端保命）：找最近可达食物，BFS从候选中选最短到达食物的最优方向，标记为承诺
HP<88 或 蛇长≤7（正常承诺）：对最近食物逐一验证三条件，选评分最高方向标记为承诺：
竞速：我的距离 ≤ 最快敌手距离 + 1（容差1步）
空间：≥ 蛇长×1.35（在模拟后状态下验证）
退路：走一步后能 BFS 到达自己尾巴；若食物不在下一格，走到食物后也能 BFS 到达自己尾巴
承诺方向评分：食物价值 / (距离+1) + 空间×0.5（菜包子价值 < 蟠桃价值）
【P4】分数压力成长控制器
感知到成长压力时激活，在安全前提下以食物为核心打分，驱动蛇积极吃东西变长。
激活条件：压力值 ≥ 0.46 且 HP ≥ 72 且 蛇长 ≤ 8。
压力值计算（0～1，各因素叠加后 clamp）：
● 蛇长越短 → 加压越高
● 成长值（蛇长 + grow_pending）越小 → 加压越高
● 每有 1 条对手成长值领先 ≥ 2 → 加压（有上限）
● HP ≥ 72 → 加压；HP < 65 → 减压；蛇长 ≥ 10 → 减压
候选过滤（保底安全）：出口 ≥ 2 且 空间 ≥ max(10, 蛇长+4) 且尾可达；
跳过：敌方比我快 > 2 步的食物直接跳过。
评分 = 基础分 + 各食物分累加：
● 基础分：空间 + 出口 + Voronoi 领地得分（此处 Voronoi 权重高于 P6）
● 食物价值 × 压力值 / 距离衰减
● 通道缩短步数 × 压力值 / 距离衰减（最大食物激励项，奖励"走这步能更快到达食物"）
● 竞速奖励：比敌快时正奖励，慢时轻微惩罚
● 直接踩食额外奖励：蟠桃 > 菜包子
【P5】紧急食物方向（urgent = HP < 65 或 蛇长 < 5）
找能缩短到食物距离、空间≥max(8, 蛇长+3)、且敌手不比我快>2步的候选方向。
紧急系数：HP<35时更高，否则约2.7倍。找到则更新 current_best（不直接返回）。
【P6】2-ply 轻量战术评分
作用：对所有候选方向打综合分，得分最高者为最终决策。
即时得分（正向）
空间 + 出口 空间（上限 80 格）× 权重 + 出口数 × 权重。越大越安全。
食物评分（最近 5 个食物） `urgency × 食物价值 × race_factor / (dist+1)`
● urgency 三档：HP<35 最高 / urgent 状态或压力≥0.55 次之 / 普通最低
● race_factor 三档：比敌快=高系数 / 差距≤2步=中系数 / 明显落后=低系数
Voronoi 领地得分：估算走这步后能控制的格子范围，权重约为 P4 的 56%。
尾可达：可达给正奖励；不可达给惩罚，低 HP 时惩罚 ×1.6。
中心距离惩罚：离中心越远轻微扣分，鼓励留在场地中央。
直接踩食奖励：下一步就能吃到时额外加分；蟠桃 > 菜包子；urgent 状态奖励加倍；随压力值额外叠加。
蜘蛛精近场扣分：曼哈顿 ≤ 2 时提前扣分警示。
踩蜘蛛精：大幅扣分（HP-60，接近送命）。
压制弱蛇（敌长 < 自身，距离 ≤ 3）：距离越近奖励越高；走这步能减少敌出口时额外奖励。
同等身长碰头惩罚：等长碰头双死，给负分阻止主动送头。
承诺方向加分：全局最大单项加分，确保 P3 锁定的方向在无致命风险时必然胜出。
附加硬惩罚（叠加在即时得分上）
尾不可达：重惩罚。
出口 ≤ 1 且空间 < 蛇长×3：中等惩罚。
敌方响应惩罚（取所有敌蛇中最坏单条的最坏一步）：情形	惩罚
强蛇进入我的下一格	重惩罚（碰头有死亡风险）
弱蛇进入我的下一格	轻微奖励（可以吃掉它）
强蛇移动到曼哈顿=1 处	适量惩罚（下回合有碰头威胁）
我的空间被压缩	压缩越多惩罚越高（上限 80 格）
我的出口减少	每少一个施加惩罚；若敌移后 `new_exits≤1` 且 `new_space < max(10, 蛇长×2)`，额外惩罚
最近 3 个食物被抢	敌方距离≤我且敌长≥我长-1 时按食物价值惩罚（蟠桃系数>菜包子）；我离食物越近惩罚越重
